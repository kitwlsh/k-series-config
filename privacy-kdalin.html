최종 개정일자: 2026년 9월 29일

요약: K달인은 회원가입·로그인이 없고, 이름·이메일·전화번호 등 사용자를 식별하는 정보를 일절 수집하지 않습니다. 풀이 기록과 오답노트는 사용자 기기 안에만 저장되며 개발자 서버로 전송되지 않습니다. 다만 본 앱은 Google AdMob 광고를 표시하므로 광고 식별자(광고 ID)가 수집·이용됩니다(제6조).

🗑 데이터 삭제 요청 방법 (K달인 · 개발자 KitwLSH)

K달인은 사용자 데이터를 개발자 서버에 전혀 저장하지 않습니다. 모든 기록이 사용자 기기 안에만 있으므로, 삭제를 위해 개발자에게 요청할 필요 없이 사용자가 직접 즉시 삭제할 수 있습니다.

① 한 번에 전부 삭제 — 기기의 설정 › 애플리케이션 › K달인 › 저장공간 › 데이터 삭제, 또는 앱을 삭제(제거)하면 풀이 기록·오답노트·설정 값이 즉시 완전히 파기됩니다.

② 삭제되는 데이터

  • 즉시 파기: 풀이 기록(푼 날짜·걸린 시간·맞힌 개수), 오답노트, 날짜별 도전 기록, 앱 설정 값, 내려받아 둔 문항 데이터 전부
  • 휴지통·유예 기간 없음 — 삭제하면 바로 사라집니다.
  • 개발자 서버 보관분: 없음 — 애초에 수집·저장하지 않습니다.

③ 광고 식별자(광고 ID)는 앱이 아니라 기기(Android)가 관리합니다. 기기의 설정 › Google › 모든 서비스 › 광고에서 광고 ID를 재설정하거나 삭제할 수 있습니다(제6조). 문의: kitwlsh@gmail.com

제1조 (개인정보의 처리 목적 및 수집 항목)

개발자가 서비스하는 안드로이드 애플리케이션 'K달인'(이하 '앱')은 회원가입·로그인 기능이 없으며, 이름·이메일·전화번호·연락처·위치·사진 등 사용자를 식별할 수 있는 개인정보를 수집하지 않습니다. 사용자가 앱에서 만들어 내는 학습 기록은 전부 사용자 기기 내부(로컬 저장소)에만 저장되며 개발자의 자체 서버로 전송·보관되지 않습니다. 앱 작동을 위해 요구되는 권한 및 처리 목적은 다음과 같습니다.

  • 인터넷 / 네트워크 상태 (android.permission.INTERNET, ACCESS_NETWORK_STATE)
    • 목적: ① 퀴즈 문항 데이터 파일을 내려받고(공개된 GitHub 저장소의 JSON 파일, 하루 1회), ② K-시리즈 자매앱 목록(공개 구성 파일)을 내려받아 표시하며, ③ 광고를 요청·표시하기 위해 네트워크에 연결합니다.
    • 전송되는 정보: ①②는 내려받기만 하는 단방향 요청으로, 사용자의 풀이 기록·성적·식별 정보를 어떤 것도 전송하지 않습니다. ③ 광고 요청에 관하여는 제6조를 참고하시기 바랍니다.
  • 광고 식별자 (com.google.android.gms.permission.AD_ID) 및 Android 광고 서비스 접근 (ACCESS_ADSERVICES_AD_ID / ATTRIBUTION / TOPICS)
    • 목적: Google AdMob 광고를 표시하고 광고 성과를 측정하기 위해 사용됩니다. 이 권한들은 Google의 광고 SDK가 자동으로 포함하는 것으로, 앱이 사용자에게 별도로 동의를 요구하는 '위험 권한'은 아닙니다. 상세 내용과 거부 방법은 제6조에 있습니다.
  • 백그라운드 작업 (FOREGROUND_SERVICE, WAKE_LOCK)
    • 목적: 하루 1회 문항 데이터를 내려받는 동기화 작업(Android 표준 WorkManager)이 안정적으로 끝나도록 하기 위해 사용됩니다. 사용자의 위치·활동을 감시하거나 기록하는 데 쓰이지 않습니다.
  • 설치된 앱 목록 조회 (<queries> 선언)
    • 목적: 'K-시리즈 자매앱' 안내 화면에서 해당 앱이 이미 설치되어 있는지 표시하고 바로 실행할 수 있도록 하기 위해 사용됩니다.
    • 범위: 본 앱은 기기에 설치된 전체 앱 목록을 조회하는 권한(QUERY_ALL_PACKAGES)을 사용하지 않습니다. 매니페스트에 명시한 개발자 본인의 자매앱 패키지에 한정해 설치 여부를 확인하며, 확인 결과는 화면 표시에만 쓰이고 외부로 전송되지 않습니다.
  • 저장소 (앱 전용 영역)
    • 목적: 내려받은 문항 데이터와 사용자의 학습 기록을 앱 전용 저장 영역에 저장·관리하기 위해 사용됩니다. 기기의 사진·파일에 접근하는 저장소 권한은 요구하지 않습니다.
    • 저장되는 항목: 풀이 기록(단계·모드·시작 시각·걸린 시간·맞힌 개수), 오답노트(틀린 내용·정답·해당 어문 규정·사전 뜻풀이), 날짜별 도전 기록, 앱 설정 값. 모두 개인을 식별하지 않는 학습 기록입니다.

제2조 (개인정보의 처리 및 보유 기간)

개발자는 사용자의 개인정보를 자체 서버에 저장 또는 보유하지 않으므로 서버 보유 기간이 존재하지 않습니다. 앱 내에서 생성되는 학습 기록·설정 정보 및 내려받은 문항 데이터는 사용자 기기에 저장되며, 사용자가 앱을 삭제하거나 앱 데이터를 초기화하는 경우 즉시 완전하게 소멸됩니다.

다만 사용자가 기기 또는 Google 계정에서 안드로이드 자동 백업을 켜 둔 경우, 앱 데이터가 사용자 본인의 Google Drive 계정에 백업될 수 있습니다. 이는 Android 운영체제가 제공하는 기능으로 개발자는 해당 백업본에 접근할 수 없으며, 기기 설정에서 백업을 끄거나 백업본을 삭제할 수 있습니다.

제3조 (개인정보의 파기절차 및 파기방법)

사용자가 단말기에서 앱을 삭제할 경우 기기 내부 저장소에 기록된 앱 관련 데이터(학습 기록, 오답노트, 설정 값, 내려받은 문항)는 즉시 안전하게 자동 삭제(파기)됩니다. 구체적 절차는 문서 상단의 🗑 데이터 삭제 요청 방법을 참고하시기 바랍니다.

제4조 (정보주체의 권리·의무 및 그 행사방법)

사용자는 앱 삭제 또는 기기 설정의 데이터 초기화를 통해 로컬에 저장된 모든 데이터의 열람·파기 권한을 직접 즉시 행사할 수 있습니다. 개발자가 보관하는 사용자 정보가 존재하지 않으므로 별도의 열람·정정·삭제 청구 절차를 두지 않으나, 문의 사항이 있는 경우 제7조의 창구로 연락하시면 회신드립니다.

제5조 (개인정보의 안전성 확보조치)

개발자는 사용자 데이터를 자체 서버에 보관하지 않으며, 기기 로컬 저장을 원칙으로 하여 유출 위험을 최소화하고 있습니다. 앱이 외부와 주고받는 통신은 모두 HTTPS 암호화로 이루어집니다. 또한 본 앱은 생성형 AI 서비스를 이용하지 않으므로, 사용자의 학습 기록이 외부 AI 서비스로 전송되는 일이 없습니다.

앱의 문항과 해설은 설치할 때 함께 들어 있거나 앞서 내려받아 둔 데이터를 쓰므로, 문제를 풀고 채점하고 해설을 보는 과정 전부가 네트워크 연결 없이 기기 안에서 완결됩니다.

제6조 (개인정보 자동 수집 장치의 설치·운영 및 거부 — 광고)

본 앱은 무료로 제공되며, 운영을 위해 Google LLC의 모바일 광고 서비스(Google AdMob)를 통해 광고를 표시합니다. 이 과정에서 광고 식별자(Advertising ID)가 수집·이용됩니다.

  • 표시되는 광고: ① 결과 화면 하단의 배너 광고, ② 연습을 여러 차례 마쳤을 때 표시되는 전면 광고, ③ 사용자가 직접 선택하여 시청하는 보상형(리워드) 광고입니다. 보상형 광고는 시청하지 않아도 앱의 모든 학습 기능을 정상적으로 이용할 수 있습니다.
  • 수집 주체와 항목: 광고 식별자, 기기·네트워크 정보(기기 모델, 운영체제 버전, 대략적 위치, IP 주소 등), 광고 노출·클릭 기록은 개발자가 아니라 Google이 자사의 광고 SDK를 통해 직접 수집합니다. 개발자는 이 정보를 전달받거나 별도로 저장하지 않으며, 사용자의 학습 기록·성적을 광고 서비스에 제공하지 않습니다.
  • 이용 목적: 광고 게재, 노출 빈도 제한, 부정 클릭 방지, 광고 성과 측정 및 (동의한 경우) 맞춤형 광고 제공.
  • Google의 처리방침: 수집된 정보의 처리는 Google의 정책을 따릅니다 — Google 개인정보처리방침 · Google이 파트너의 사이트·앱에서 정보를 사용하는 방법.

■ 유럽 경제 지역(EEA)·영국·스위스 이용자의 동의
해당 지역에서는 GDPR 및 ePrivacy 지침에 따라, 앱 최초 실행 시 Google의 사용자 메시지 플랫폼(UMP)을 통한 동의 양식이 표시됩니다. 사용자는 맞춤형 광고에 대한 동의 여부를 선택할 수 있으며, 동의하지 않아도 앱의 모든 학습 기능을 그대로 이용할 수 있습니다(비맞춤형 광고가 표시됩니다). 선택한 동의는 앱의 [설정] 화면에서 언제든지 다시 열어 변경할 수 있습니다.

■ 거부·차단 방법 (모든 지역 공통)

  • 광고 ID 재설정 또는 삭제: 기기의 설정 › Google › 모든 서비스 › 광고에서 광고 ID를 재설정하거나 완전히 삭제할 수 있습니다. 삭제하면 맞춤형 광고가 중단됩니다.
  • 앱 내 동의 변경: K달인 [설정] › 광고 동의 설정(해당 지역에 한함).

본 앱은 위 광고 목적 외에 사용자의 활동을 추적하는 별도의 분석(Analytics)·통계 도구나 쿠키를 사용하지 않습니다. 개발자는 사용자가 어떤 문제를 풀었는지, 몇 점을 받았는지 알 수 없습니다.

제8조 (제3자 제공 및 처리 위탁)

개발자는 사용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 앱이 외부 서비스와 통신하는 경우는 다음이 전부입니다.

  • Google LLC (Google AdMob · 사용자 메시지 플랫폼) — 광고 게재 및 동의 관리. 수집 항목과 거부 방법은 제6조 참고.
  • GitHub, Inc. (raw.githubusercontent.com) — 퀴즈 문항 데이터 파일과 자매앱 목록 파일을 내려받기 위한 요청. 일반적인 웹 요청과 마찬가지로 접속 IP 등 통신 기록이 GitHub 측에 남을 수 있으나, 앱이 사용자 정보를 담아 보내는 것은 없으며 개발자는 그 기록에 접근하지 않습니다.
  • 국립국어원 표준국어대사전 (stdict.korean.go.kr) — 사용자가 해설 화면에서 [사전에서 더 보기]를 직접 누른 경우에만, 기기의 웹 브라우저가 해당 낱말의 사전 페이지를 엽니다. 이때부터는 앱이 아니라 사용자의 브라우저가 수행하는 일반적인 웹 접속이며, 앱이 사용자 정보를 함께 전달하지 않습니다.
  • 결과 공유 — 사용자가 [결과 공유]를 직접 실행한 경우, 결과 이미지를 사용자가 선택한 앱(메신저·메일 등)에 전달합니다. 전달 여부와 대상은 전적으로 사용자가 선택하며, 개발자는 공유된 내용을 알 수 없습니다.

본 앱은 생성형 AI 서비스를 이용하지 않으므로, 사용자의 어떠한 데이터도 외부 AI 서비스로 전송되지 않습니다.
